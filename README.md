# Noman Ejaz CV / Portfolio

A responsive personal portfolio and CV built with HTML, CSS, and JavaScript.

## Local preview

Open the project folder and run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## GitHub Pages deployment

1. Push this folder to a GitHub repository.
2. Open the repository on GitHub.
3. Go to Settings > Pages.
4. Under Source, choose Branch: `main` and Folder: `/root`.
5. Save.
6. Your site will be published at:

```text
https://<your-username>.github.io/<repository-name>/
```

## Files

- `index.html` — main page content
- `style.css` — styling and layout
- `script.js` — interactivity and effects
